
# Maps

Maps help you represent and explore your world. Use **Map Explorer** to browse the map, inspect its markers, and—if you can edit it—create and update map content directly on the canvas.

Map Explorer is designed for world maps rather than a tactical battle map with live player movement.

## Large-map tiling

Kanka automatically tiles large map images into smaller pieces. This lets Map Explorer load and zoom large maps more quickly, without requiring any extra setup from you.

Tiling happens in the background after you upload or replace a qualifying image. While it is processing, the map is temporarily unavailable; refresh or return to Map Explorer a few minutes later. Older large maps may show a one-time migration prompt in Map Explorer so they can benefit from the same faster loading.
