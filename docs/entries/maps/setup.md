# Map Setup

The regular map edit page is where you set up the map itself. Map Explorer has its own **Map settings** panel for settings you may want to adjust while viewing the map.

* **Parent Map**: If this level 3 of a bigger dungeon that also is a map? If so, use the parent map to "place" this map inside another.
* **Location**: Useful if this map is the map of a kingdom, town, dungeon, etc. Link the location, and the map will be available in the location's profile sidebar.
* **Image**: This is the main image, which will serve as the map image, and also the thumbnail image of the map in lists.

## Settings

The map edit page's **Settings** tab still contains all map settings. In Map Explorer, open the map name menu and select **Map settings** to change the grid, zoom levels, distance unit, center, or pin style without leaving the map. These two places update the same values.

The following settings are only available from the regular map edit page.

* **Use OpenStreetMaps**: If you want to use a map from the real world instead of a custom image, check this option. You still need an image for the map, but it will only be used as a thumbnail.
* **Cluster markers**: After adding several markers on your map, it will quickly become messy and unreadable. This option clusters markers that are close together until you zoom in enough.

### Grid

Set a grid size to show a grid over an image map. Leave it empty to hide the grid.

### Zoom levels

The minimum and maximum zoom limit how far readers can zoom out and in. The initial zoom is the zoom level used when the map opens. You can change all three in either settings surface.

### Centering

By default, a map loads at coordinates 0,0. In Map Explorer, choose **Pick center on map** and click the location you want, or choose **Center marker** and select a marker. The regular map edit page also lets you enter coordinates manually.

### Distance and measurement

Set both the **Distance Unit label** (for example, `km` or `miles`) and **Distance measurement** to enable the ruler in Map Explorer. The measurement value converts map distance into your chosen unit.

### Pin style

Map Explorer uses compact icons for pins by default. Enable **Use legacy pin style** in Map Explorer's Map settings if you prefer the older coloured teardrop pins.

### Large maps

For eligible large maps using the older image mode, Map Explorer offers a migration prompt. Migrating tiles the image so the map loads faster. The map is unavailable briefly while this runs.
